# «Папа вернулся с вахты» — TikTok-анимация (серия)

Формат «Он или не он?»: 6 признаков, 16 кадров, 90 секунд, 1080×1920, 30 fps.
Только звуковые эффекты, без музыки и озвучки. Всё нарисовано кодом (Remotion + SVG), звуки синтезируются скриптом. Готовых ассетов нет.

## Запуск

```bash
npm install
npm run sfx        # сгенерировать звуки в public/sfx (уже лежат в репозитории)
npm run studio     # превью с таймлайном в браузере
npm run render     # итоговый файл: out/papa-vakhta.mp4
```

Быстрый просмотр отдельных кадров: `node scripts/stills.mjs out/sheet.png 100 500 900`.

## Озвучка (ElevenLabs)

Один рассказчик на всё видео (как в референсе), модель `eleven_v3`. Текст, голос и время каждой реплики: `src/voice-lines.json`.
Разметка для субтитров: `*слово*` — красный, `«цитата»` — жёлтый; `whisper` — цитата шёпотом.

```bash
npm run voice -- --dry        # проверить тексты и тайминг без запросов (ничего не тратит)
npm run voice                 # сгенерировать новые/изменённые реплики
npm run voice -- --voice <id> # попробовать другой голос
npm run render
ffmpeg -i out/papa-vakhta.mp4 -c:v copy -af loudnorm=I=-14:TP=-1.5 -c:a aac -b:a 192k out/papa-vakhta-final.mp4
```

Ключу ElevenLabs нужны права **Text to Speech**, а для выбора русского голоса из библиотеки ещё **Voices: Read/Write**.
Пока озвучки нет, субтитры идут по расчётному времени, поэтому видео можно смотреть как превью.

## Своя озвучка из ElevenLabs (готовый mp3)

Озвучку можно сделать вручную на сайте ElevenLabs по тексту из `src/voice-lines.json` и подставить в видео:

```bash
python3 scripts/fit-voiceover.py assets/voiceover.mp3   # режет на фразы, ставит каждую на свой кадр
npm run render
ffmpeg -i out/papa-vakhta.mp4 -c:v copy -af loudnorm=I=-14:TP=-1.5 -c:a aac -b:a 192k out/papa-vakhta-final.mp4
```

Скрипт находит фразы по паузам, сопоставляет их с репликами, укорачивает длинные паузы,
слегка ускоряет весь голос (по умолчанию в 1.12 раза, `BASE_TEMPO=1.0` — без ускорения),
выравнивает громкость и пишет время каждого слова для субтитров.

## Новый сериал «Голосовые из завтра», серия 1 «Не садись в лифт»

Код: `src/g1/` (тайминг, текст озвучки, сцены, звуки). Главный герой — новый персонаж `kind="teen"`
(чёрные торчащие волосы, круглые очки, красное худи, чёрный рюкзак), не сын из «Папы». Сверху вместо «Он или не он?» счётчик
«СБЫЛОСЬ: n/7» с галочками, таблички «СБЫЛОСЬ №n». Реплики с `"phone": true` в `voice-lines.json`
скрипт обрабатывает как голосовое из телефона (узкая полоса частот, лёгкий «цифровой» хруст),
а волна в пузыре голосового двигается по громкости этих реплик (`src/g1/env.json`).
Счётчик на 2 предсказания: лифт — ✓ (сбылось), мяч — «?» (под вопросом, поле `pending` в `src/g1/timeline.ts`).

Время каждого слова для субтитров меряется по самим кусочкам озвучки (`scripts/word_timing.py`):
фраза делится на отрезки речи по паузам, слова раскладываются по отрезкам с учётом того, как они
произносятся (числа читаются словами: «23:41» = «двадцать три сорок одна»). Пересчитать без повторной подгонки:
`python3 scripts/word_timing.py --part g1`.

```bash
python3 scripts/fit-voiceover.py assets/golosovye-1.mp3 --part g1
npx remotion render Golosovye1 out/golosovye-1.mp4
ffmpeg -i out/golosovye-1.mp4 -c:v copy -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:a aac -b:a 192k deliverables/golosovye-1-s-ozvuchkoy.mp4
```

## Новый сериал «Фильм про тебя», часть 1 (продолжение «Папа вернулся с вахты»)

Идея автора канала: ты приходишь в кино, а фильм — про тебя (про то, как к тебе вернулся папа с вахты).
Версия 2 (по просьбе автора): сначала идёт обычный мультик про космос «Звёздный патруль» (`SpaceToon`, своя
мелодия `sfx/toon.wav`), потом сбой (`BrokenFeed`: картинка дёргается, полосы, звук пропадает) — и на экране
уже твоя жизнь. Полный зал смеётся, будто идёт мультик: этого не замечает никто, кроме тебя; кассирша тоже
ничего не знает (зевает и продаёт билеты на мультик).
Код: `src/f1/` (композиция `Film1`). Герой — сын из «Папы», настоящий папа рядом. Зал спереди (`HallFront`: ряды
красных кресел `Seat`, чётные ряды сдвинуты на полкресла, перед 7-м рядом проход; зрители — `Viewer` в обычной
одежде, `Person plain`; `dim` приглушает всех, кроме героев; сидящие в 7-м ряду — `Sitter`). Свободно одно
кресло во всём зале — за спиной сына (8-й ряд). Экран из-за спин зрителей (`ScreenView`: на экране идёт сцена
1080×1920, видна её средняя полоса; внизу силуэты голов), фильм на экране — настоящие кадры «Папы»
(`P1a.S01/S03/S04`, `P6.S10`) и `FilmTitle`, «этот же зал» на экране — `FilmHall`. Сверху вместо часов — время
фильма, которое бежит до «ФИЛЬМ · СЕЙЧАС»; справа счётчик «КАК В ФИЛЬМЕ». Если одна и та же сцена с персонажами
рисуется в кадре дважды, у копий должны быть разные `id` (иначе тень одной копии ссылается на другую).
Новые звуки (`node scripts/make-sfx.mjs`): `applause` (зал хлопает), `crunch` (попкорн), `toon` (мелодия мультика).


## «Ты с какого района?»: мигание фона и другие поправки (обе серии)

- **Мигание домов и стен на заднем плане.** Chrome иногда делал снимок кадра до того, как дорисовывал большие 3D-слои
  (дома, стены), и на один кадр кусок фона пропадал. Теперь в `remotion.config.ts` стоит
  `Config.setChromiumFlags({'run-all-compositor-stages-before-draw': true})` (то же в `scripts/stills.mjs` и
  `scripts/crops.mjs`): кадр снимается только после полной отрисовки. Проверка готового видео:
  `python3 scripts/find-flicker.py out/rayon-2.mp4` — должно быть «0 flicker frames». До исправления во 2-й серии было
  39 таких кадров.
- **Дверь качалки больше не утоплена в асфальт.** Земля в ближнем проходе тянулась до горизонта и закрывала нижнюю
  половину двери. Теперь она заканчивается у стены (`KachalkaGround`). Землю нельзя класть в один проход со стеной:
  тогда Chrome выбрасывает стену целиком.
- Лампочки у двери и в качалке горят ровно, без мерцания.
- Длинные слова в субтитрах («ТЕПЛОКОНТРОЛЬ», «ТЯП-ЛЯПОВСКИЙ») набираются мельче и не переносятся по дефису.

двери их подвальной качалки. Финал, как в других сериях: «1 ПРИШИТЬСЯ / 2 НЕ ПРИШИТЬСЯ» (пиши 1 или 2). Персонажи и сюжет свои; Тяп-ляп — реальная
казанская группировка 70-х, но все люди в серии вымышленные. Текст — `deliverables/s-kakogo-rayona-seriya-1-igorechek.txt`.

**Хук (первые 8 секунд), чтобы досматривали:** серия начинается с развязки — ночь, дверь их качалки (надпись
краской «КАЧАЛКА», лампочка в сетке, за дверью лязг железа), камера твоими глазами подходит, рука поднимается
постучать: «Ты стоишь у двери самой опасной группировки района. И пришёл ты сюда сам». Перемотка назад (часы в HUD
откатываются на сутки) — школьная доска, мелом «ИГОРЕЧЕК» и карикатура в шапке: «А началось всё с одного слова».
Дальше — вся история к этой двери.

Новое для неё: `src/r1/sets3d.tsx` — 3D-локации школы (здание с входом «ШКОЛА № 17», забор с калиткой и кирпичными
столбами, лужа с кругами), раздевалка (ряды пальто проезжают мимо камеры), комната Игоря (ковёр на стене, луна в
окне, полоска света из-под двери), реквизит (портфель, авоська). `Person`: вязаная шапка-«петушок» (`knit`), синяк
под глазом (`face.bruise`). Школьницы — в коричневых платьях с белыми фартуками.

**Озвучка этой версии сделана мной через ElevenLabs** (`scripts/tts-lines.py`: запрос на строку с соседними строками
как контекстом, склейка с паузами в один mp3, дальше обычный `fit-voiceover.py`). Голос прошлой серии «Broken Future
– Narrator» (ID `zWSsRd3J6WyZFl12aGMB`) библиотечный: через API он работает только на платном тарифе ElevenLabs
(«Free users cannot use library voices via the API»). Поэтому серия озвучена стандартным голосом Adam (`eleven_v4`,
stability 0.5, similarity 0.75) без обработки — пониженный на 5 полутонов вариант звучал плохо. С платным тарифом
переозвучить голосом прошлой серии: `python3 scripts/tts-lines.py zWSsRd3J6WyZFl12aGMB src/r1/voice-lines.json
assets/rayon-1-igorechek.mp3` и снова подгонка.

**Версия 2 — «3D-камера» (2.5D) и новый главный герой** (всё это осталось и в версии 3). Всё по-прежнему рисованное 2D, но плоские слои — дома,
гаражи, деревья, люди, мебель — стоят на настоящей глубине в CSS-3D, и камера ездит между ними: ближние слои
проезжают быстрее дальних, земля, пол и потолок уходят в перспективу, у домов есть боковые стены, задний план
размыт, как у объектива (глубина резкости). Камера в каждом кадре движется: кран вверх над двором в начале,
проезд вдоль забора, наезды на героя. Главный герой новый — рыжий мальчик «под горшок» с веснушками и
оттопыренными ушами (`Person` kind `'boy'`), чтобы не путать его с сыном из «Вахты».

Как это устроено:
- `src/components/Scene3D.tsx` — сцена `Scene3D` (перспектива 1300 px, камера `Cam3 {x, y, z, rx, ry}`), плоская
  карточка `Card3D` (SVG или HTML на глубине `z`, можно повернуть `ry` — боковые стены), горизонтальная плоскость
  `Floor3D` (земля, пол, потолок, столешница; растрируется в `res` раз меньше, иначе огромные слои браузер не
  рисует), коробка `Box3D` (фасад + боковая стена). Дальний план (`far`) рисуется отдельным проходом и размывается
  целиком — это и есть «глубина резкости»; размывать огромные слои по одному Chrome не умеет (пропадают).
  `project(cam, x, y, z)` — где точка мира окажется на экране (для табличек, пузырей и подписей поверх 3D).
- Мир: 1 м ≈ 300 px, земля на y = 0, вверх — минус. Кадр 1080×1920, точка схода в центре.
- `src/r1/world3d.tsx` — двор 1976 года из слоёв: хрущёвки-коробки, гаражи, кирпичный завод с трубой и дымом,
  деревья, забор, лавка, асфальт с листьями (`YardFar` — дальний план, `YardNear` — ближний), небо днём / в сумерках
  / ночью (`skyBg`), `Figure3D` — персонаж на карточке.
- Кухня (кадр 9) — настоящая коробка: пол, потолок с лампой, три стены, стол с клеёнкой (сверху видна столешница),
  плита, холодильник «ЗИЛ» с боковой стенкой. Задняя стена — отдельным проходом: когда камера наезжает и пол с
  потолком уходят ей «за спину», Chrome иначе не дорисовывает часть дальнего слоя.
- Подписи стоят на y ≈ 1170–1270, поэтому камеры выставлены так, чтобы лица, монетка и карманы были выше них;
  таблички «понятий» поднимаются выше лица (`y` у знака в `timeline.ts`).

Персонажам добавлены опции (`Person`): `cap` — кепка, `quilt` — телогрейка со стёжкой, `pioneer` — белый воротник
и пионерский галстук; `plain` у «худи»-персонажей даёт простой пиджак без капюшона (у `Bust` — куртка с лацканами).
